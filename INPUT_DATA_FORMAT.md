## Multi-Omics Data Files

### Files Needed
- **Transcriptomics data**: `Strep_transcriptome_data.csv`
- **Proteomics data**: `Strep_proteome_data.csv`
- **Metabolomics data**: `Strep_metabolome_GC_data.csv`

### Format Requirements

These CSV files should be **feature × sample matrices** with the following structure:

```
Column 1: Feature IDs (will become row names)
Columns 2-N: Sample measurements
```

**Example Structure:**
```
X,Sample1_RPMI,Sample2_RPMI,Sample3_RPMI,Sample1_SERUM,Sample2_SERUM,Sample3_SERUM
Gene_001,5.23,5.45,5.12,7.89,8.01,7.67
Gene_002,3.45,3.78,3.56,3.34,3.29,3.41
Gene_003,12.34,11.98,12.45,6.78,6.92,6.54
```

### Detailed Specifications

#### Column 1: Feature Identifiers
- **Header**: Can be named "X", "ID", or any identifier column name
- **Content**: Unique identifiers for each molecular feature
  - Transcriptomics: Gene IDs (e.g., locus tags, gene symbols)
  - Proteomics: Protein IDs (e.g., UniProt IDs, protein groups)
  - Metabolomics: Metabolite IDs or compound names
- **Requirements**: 
  - Must be unique (no duplicates)
  - Should match IDs used in annotation files

#### Columns 2-N: Sample Measurements
- **Headers**: Sample names that clearly indicate condition
  - Recommended format: `SampleID_Condition` (e.g., `Bio1_RPMI`, `Bio1_SERUM`)
  - Consistent naming helps track replicates
- **Content**: Normalized expression/abundance values
  - Transcriptomics: log2(CPM), log2(TPM), or normalized counts
  - Proteomics: log2(LFQ intensity) or normalized abundances
  - Metabolomics: log2(peak area) or normalized concentrations
- **Requirements**:
  - **Same sample order across all omics files** (critical for DIABLO)
  - Numeric values only (no missing values; use 0 or NA)
  - Already normalized and log-transformed if appropriate
  - Number of samples must match across all omics layers

#### Sample Size
- **Minimum**: 6 samples per condition (12 total for 2 conditions)
- **Recommended**: 20-30 samples per condition for robust statistics
- **Maximum**: No hard limit, but very large datasets may require more memory

#### Example Files
See provided example files in `Data/` directory:
- `Strep_transcriptome_data.csv`: 5,186 genes × 60 samples
- `Strep_proteome_data.csv`: 1,234 proteins × 60 samples  
- `Strep_metabolome_GC_data.csv`: 136 metabolites × 60 samples

## Differential Expression Results

### File: `All_entity_fold_change_long_format.rds`

This file contains differential expression/abundance results for **enrichment analysis** (ORA/GSEA).

### Format: R Data Frame (Long Format)

**Required Columns:**
```
entity_id         : Unique feature identifier (matches omics data)
species           : Species name (e.g., "Streptococcus pyogenes")
strain            : Strain identifier (e.g., "5448", "HKU419")
experiment        : Omics type (e.g., "Transcriptomics RG", "Proteomics MS1 DDA", "Metabolomics GC-MS")
logFC             : Log2 fold change (condition2 vs condition1)
FDR               : False discovery rate (adjusted p-value)
is_species_core   : "yes" or "no" (whether gene is in core genome)
```

**Example Rows:**
```
entity_id    species                  strain  experiment          logFC   FDR      is_species_core
Gene_001     Streptococcus pyogenes  5448    Transcriptomics RG  2.45    0.001    yes
Gene_002     Streptococcus pyogenes  5448    Transcriptomics RG  -1.23   0.045    yes
Prot_001     Streptococcus pyogenes  5448    Proteomics MS1 DDA  1.89    0.012    yes
```

### How to Create This File

1. **Run differential expression analysis** using appropriate tools:
   - Transcriptomics: DESeq2, edgeR, limma
   - Proteomics: limma, MSstats
   - Metabolomics: limma, MetaboAnalyst

2. **Extract required information**:
   ```r
   # Example for DESeq2 results
   library(DESeq2)
   dds <- DESeq(dds_object)
   res <- results(dds)
   
   # Convert to data frame
   de_results <- data.frame(
     entity_id = rownames(res),
     species = "Streptococcus pyogenes",
     strain = "5448",
     experiment = "Transcriptomics RG",
     logFC = res$log2FoldChange,
     FDR = res$padj,
     is_species_core = "yes"  # Adjust based on your annotation
   )
   ```

3. **Combine results from all strains and omics**:
   ```r
   all_DE <- rbind(
     de_results_strain1_transcriptomics,
     de_results_strain1_proteomics,
     de_results_strain2_transcriptomics,
     # ... etc
   )
   
   saveRDS(all_DE, "All_entity_fold_change_long_format.rds")
   ```

## Functional Annotation Files

### File: `All_funct_annot_clean_noduplicate.rda`

This file maps molecular features to functional terms (GO, KEGG, etc.) for **pathway enrichment analysis**.

### Format: R Data Frame

**Required Columns:**
```
entity_id      : Feature identifier (matches omics data and DE results)
entity_type    : Type of feature ("gene", "protein", or "metabolite")
fterm_id       : Functional term ID (e.g., "GO:0006096", "map00010")
fterm_name     : Functional term description (e.g., "glycolytic process")
fterm_origin   : Database source (e.g., "GO", "KEGG")
```

**Example Rows:**
```
entity_id   entity_type   fterm_id      fterm_name                    fterm_origin
Gene_001    gene         GO:0006096    glycolytic process            GO
Gene_001    gene         map00010      Glycolysis / Gluconeogenesis  KEGG
Gene_002    gene         GO:0055114    oxidation-reduction process   GO
Prot_001    protein      GO:0006412    translation                   GO
Met_001     metabolite   C00031        D-Glucose                     KEGG
```

### How to Create This File

#### For Genes/Proteins:

1. **Get functional annotations** from databases:
   - **GO terms**: Use Bioconductor packages like `org.*.db` or `biomaRt`
   - **KEGG pathways**: Use `KEGGREST` or download from KEGG database
   - **Other databases**: COG, InterPro, Reactome, etc.

2. **Example using Bioconductor**:
   ```r
   library(org.Hs.eg.db)  # For human; use appropriate package for your organism
   
   # Get GO annotations
   go_annot <- select(org.Hs.eg.db, 
                      keys = gene_ids,
                      columns = c("GO", "TERM"),
                      keytype = "ENTREZID")
   
   # Format for pipeline
   annot_df <- data.frame(
     entity_id = go_annot$ENTREZID,
     entity_type = "gene",
     fterm_id = go_annot$GO,
     fterm_name = go_annot$TERM,
     fterm_origin = "GO"
   )
   ```

#### For Metabolites:

1. **Get compound annotations** from:
   - KEGG Compound database
   - HMDB (Human Metabolome Database)
   - ChEBI (Chemical Entities of Biological Interest)

2. **Map metabolites to pathways**:
   ```r
   library(KEGGREST)
   
   # Get KEGG compound pathway mapping
   cpd_info <- keggGet(metabolite_ids)
   
   # Extract pathway information
   # Format similarly to gene annotations
   ```

3. **Combine all annotations**:
   ```r
   all_annot <- rbind(
     gene_annotations,
     protein_annotations,
     metabolite_annotations
   )
   
   # Remove duplicates
   all_annot <- unique(all_annot)
   
   save(all_annot, file = "All_funct_annot_clean_noduplicate.rda")
   ```

## Network Files for Shiny App

### Node File Format (`.tsv`)

**Required Columns:**
```
name                  : Pathway or term name (unique identifier)
nb_strain_with_node   : Number of strains/conditions where this pathway is enriched
gene_set_size         : Average number of genes in the pathway
p.adjust              : Comma-separated p-values from each strain
```

**Example (`Strep_all_node_trans_GSEA_KEGG.tsv`):**
```
name                        nb_strain_with_node   gene_set_size   p.adjust
map00010                    5                     25              0.001,0.002,0.001,0.003,0.001
map00020                    3                     18              0.045,0.032,0.041
Glycolysis/Gluconeogenesis  5                     25              0.001,0.002,0.001,0.003,0.001
```

### Edge File Format (`.tsv`)

**Required Columns:**
```
from                  : Source pathway name
to                    : Target pathway name
nb_strain_with_edge   : Number of strains where this connection exists
similarity            : Average Jaccard similarity coefficient (0-1)
```

**Example (`Strep_all_edge_trans_GSEA_KEGG.tsv`):**
```
from                        to                          nb_strain_with_edge   similarity
map00010                    map00020                    5                     0.45
map00010                    map00030                    3                     0.32
Glycolysis/Gluconeogenesis  Citrate cycle (TCA cycle)   5                     0.45
```

### File Creation

These files are **generated by the workflow** in script `5.1_Node_Edge_data_Strep_220425.Rmd`. However, if you want to create custom network files:

1. **Ensure tab-separated format** (not comma)
2. **Include headers** (first row with column names)
3. **Match node names exactly** in both files
4. **Use numeric values** for counts and similarity scores

## Data Formatting Tips

### General Guidelines

1. **File Encoding**: Use UTF-8 encoding for all text files
2. **Decimal Separator**: Use period (`.`) not comma (`,`)
3. **Missing Values**: 
   - For omics data: Use `NA` or `0` (check method requirements)
   - For annotations: Remove rows with missing terms
4. **Special Characters**: Avoid in feature IDs and sample names
   - Use: letters, numbers, underscores, hyphens
   - Avoid: spaces, slashes, periods (except decimals)

### Sample Naming Convention

Use consistent, informative names:
```
✓ Good:  Bio1_RPMI, Bio1_SERUM, Bio2_RPMI, Bio2_SERUM
✗ Bad:   Sample1, Sample2, S1, S2
```

### Quality Control Checks

Before running the pipeline, verify:

```r
# 1. Check dimensions match across omics
lapply(list(transcripts, proteins, metabolites), dim)
# All should have same number of rows (samples)

# 2. Check for missing values
sum(is.na(transcripts))

# 3. Verify feature IDs are unique
length(unique(rownames(transcripts))) == nrow(transcripts)

# 4. Check sample order consistency
identical(colnames(transcripts), colnames(proteins))
identical(colnames(proteins), colnames(metabolites))
```

### Example Data Loading

```r
# Load and prepare multi-omics data
library(tidyverse)

# Read CSV files
trans_data <- read.csv("Strep_transcriptome_data.csv", row.names = 1)
prot_data <- read.csv("Strep_proteome_data.csv", row.names = 1)
met_data <- read.csv("Strep_metabolome_GC_data.csv", row.names = 1)

# Verify data integrity
cat("Dimensions check:\n")
cat("Transcripts:", dim(trans_data), "\n")
cat("Proteins:", dim(prot_data), "\n")
cat("Metabolites:", dim(met_data), "\n")

# Check sample consistency
stopifnot(identical(colnames(trans_data), colnames(prot_data)))
stopifnot(identical(colnames(prot_data), colnames(met_data)))

cat("\nData loaded successfully! ✓\n")
```
