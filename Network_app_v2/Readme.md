# Interactive Network Visualisation via a Shiny Web Application


To support interactive exploration of enrichment pathway networks, we developed a dedicated R Shiny web application called Network of Enriched Pathways (https://warasinee.shinyapps.io/Network_App/). The application provides a graphical interface for filtering, visualising, and exporting the network. It requires two tab-separated input files (node and edge tables generated by the workflow). 

### Part 1. Control panel
**The control panel is divided into six subpanels in a sidebar layout: Upload data, Network filter, Visualisation style, Interactive plot, Static plot, and Node ranking.**


- To generate the **initial plot**, after uploading the node and edge tables or selecting example datasets (*S. aureus*, *S. pyogenes*), users can specify a condition threshold to restrict which nodes are displayed in the network filter panel.
- The **number of conditions** displayed can be modified to accommodate both specific and broad comparisons.
- For further **node modification**, users can select the colour palette or define custom hexadecimal codes, and select legend labels (Strains, Conditions, or Omics) to reflect the experimental context in the visualisation style panel.

### Part 2. Interactive plot
- The **interactive plot** supports real-time exploration through zooming, panning and node dragging.
- Four **network layouts** are available: Force-directed (Fruchterman-Reingold), Kamada-Kawai, Circular, and Hierarchical.
- **Node size and colour** encode the number of conditions shared in each pathway.
- **Edge thickness** is proportional to the **Jaccard similarity** between connected pathway pairs or the number of conditions sharing the same interaction.
- **Clicking on any node displays a tooltip** showing the pathway name, condition count, and the list of condition identifiers, facilitating rapid identification of shared versus condition-specific enriched pathways.
- **Nodes can be excluded** by name to remove uninformative terms, and a similarity-based grouping function allows the merging of highly similar pathways into a single node, reducing visual clutter from dense network.


### Part 3. Statistic plot
- The **static plot** mainly supports publication-ready figures, allowing export as a PNG or a scalable vector graphic (SVG) for further editing.

### Part 4. Node ranking table
- A **node ranking table** below the interactive plot summarises each pathway by its number of conditions and network degree (interactions) and allows sorting in ascending or descending order.
- The app includes **a ranking and filtering system** allowing prioritisation of the most informative and discriminatory pathways across conditions.
- The **“Network Filter”** enables users to select pathways based on how many conditions they appear in. This supports direct isolation of pathways that are conserved across all conditions (core or conserved responses) or unique to a single condition (strain-specific or treatment-specific responses).
- The **“Node Ranking”** table ranks pathways by either the number of conditions they appear in or the number of interactions they have. A node with a high condition count and many interactions indicates a broadly conserved, highly connected pathway (e.g. core metabolic response).
- A node with a low condition count and few interactions indicates a narrow, isolated pathway (e.g. condition-specific pathway). The node prioritisation directly facilitates biomarker identification.
- By combining the network visualisation with the ranking table, users can rapidly short-list candidate pathways for further studies.
